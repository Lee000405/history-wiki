
# History Wiki

A personal historical knowledge website.

## Project Overview

History Wiki is a digital knowledge project focusing on
Chinese history, military history and world history.

The project aims to organize historical knowledge in a
consistent and expandable website structure.

## Features

- Historical category navigation
- Historical article pages
- Article search
- Responsive website design
- Reusable article layout
- AI development instructions

## Technology

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Structure

```text
history-wiki/
├── AGENTS.md
├── README.md
├── index.html
├── css/
├── js/
├── pages/
├── articles/
└── assets/
```

## AI Development Rules

The AGENTS.md file defines the project's design,
content structure, file naming conventions and
AI development workflow.
