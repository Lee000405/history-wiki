
# AGENTS.md

## 1. Project Identity

Project Name: History Wiki

Purpose:
A personal historical knowledge website covering
Chinese history, military history and world history.

The website should be expandable and maintain a consistent
design across all pages.

## 2. Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

Do not introduce unnecessary frameworks or dependencies.

## 3. Design Guidelines

- Use a historical encyclopedia visual style.
- Use warm beige, dark navy and neutral colors.
- Use readable typography.
- Keep the design minimalist and professional.
- Support desktop, tablet and mobile screens.
- Maintain consistent navigation across all pages.

## 4. Project Structure

- index.html: Homepage
- css/style.css: Main stylesheet
- js/main.js: Main JavaScript
- pages/: Category pages
- articles/: Historical articles
- assets/images/: Images
- AGENTS.md: Project development instructions
- README.md: Project documentation

## 5. Website Navigation

Main navigation:

- Home
- Chinese History
- Military History
- World History
- About

All pages should provide consistent navigation.

## 6. Article Structure

Every historical article should contain:

1. Title
2. Introduction
3. Historical Background
4. Main Discussion
5. Causes and Consequences
6. Conclusion
7. References

Articles should use consistent HTML structure and CSS.

## 7. Content Guidelines

- Use clear and accurate historical explanations.
- Distinguish historical facts from interpretations.
- Do not invent historical sources.
- Include references whenever possible.
- Explain historical causes and mechanisms.
- Avoid presenting controversial interpretations as established facts.

## 8. File Naming Rules

- Use lowercase English filenames.
- Use hyphens instead of spaces.
- Store articles in articles/.
- Store category pages in pages/.
- Store images in assets/images/.

Examples:
- five-barbarians.html
- mongol-military.html
- song-crossbow.html

## 9. AI Development Rules

Before making changes:

1. Read this AGENTS.md.
2. Inspect the existing project structure.
3. Follow the existing design system.
4. Reuse existing CSS.
5. Maintain consistent navigation.
6. Avoid unnecessary duplication.
7. Do not modify unrelated files.
8. Use relative paths compatible with GitHub Pages.

## 10. Development Workflow

When creating new content:

1. Check existing files.
2. Follow the article structure.
3. Reuse existing styles.
4. Check all internal links.
5. Test responsive layouts.
6. Update README.md if necessary.

The goal is to make the website easy to maintain
and expand using AI assistance.
